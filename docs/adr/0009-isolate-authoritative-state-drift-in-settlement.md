# 可信结算事件按当前状态差异隔离

结算区块的身份、签名、摘要、连续序列、不可变快照和 charge 复核继续 fail closed；这些错误表示事件不可信或结算链损坏。事件通过完整性复核后，当前用户、token、订阅、渠道或辅助统计已经删除、变更或越界时，只隔离该事件或对应投影，持久化 Settlement Skip 并继续确认后续序列，避免一条过期业务引用永久阻断整个节点。

## Considered Options

- 整个区块原子失败并无限重试：不会遗漏单条业务事件，但会把可接受的小额偏差放大为长期主从断开。
- 为渠道、分组、订阅等对象逐类增加特判：短期改动小，但无法覆盖未来对象和异常分支。
- 按错误语义统一分层：可信性错误阻断、基础设施错误重试、当前业务状态差异按事件隔离。该方案不削弱结算链可信边界，并把业务生命周期差异限制在单条事件。

## Consequences

Settlement Skip 仍计入节点事件时间滑动窗口，防止通过删除当前对象绕过结算熔断。master 以区块总事件数确认序列，旧 edge 无需升级协议；余额回冲水位会清除已确认 skip 对应的本地 unsettled overlay，因此 skip 代表显式、可审计的小额未扣账。数据库不可用、事务错误和持久化失败不得转换为 skip。
