# Edge 使用余额副本和有界超卖异步结算

ADR 0002 的配额租约会把单次请求限制在租约上限内，并把快照有效期、租约期限和数据面可用性绑定。决定以 master 权威余额、edge 本地余额副本、心跳服务端 diff 和原有异步 settlement block 替代租约；钱包、有限 token 和订阅额度在 edge 本地预占与结算，master 收到结算后幂等扣减权威账，再由后续心跳把新余额回冲到 edge。

余额协议使用 `edge-control.v2`。master 每次心跳读取当前权威余额向量，与该节点最后确认的向量比较，只传变化条目；版本断档或 edge 本地状态重建时发送全量向量。不增加余额变更插桩、binlog、outbox、连接或轮询。

## Considered Options

- 保留租约并提高租约额度：改动较小，但仍保留额度切片、续租、TTL、跨快照关闭和大额请求受单租约上限约束的问题。
- 建设通用 CDC/binlog 基础设施：可提供通用变更流，但需要插桩或数据库级复制，扩大运维面和上游 rebase 分叉，不符合当前 79 个用户可直接全量比较的规模。
- 把全量余额放入签名策略快照：复用已有下载链路，但每次消费都会改变快照内容，击穿内容去重并持续触发全量快照编译、签名和重发。
- 每个请求同步向 master 校验余额：保持强一致，但把跨地域延迟和 master 故障重新放回用户请求路径。

## Consequences

多节点可以同时消费同一份已复制余额，系统明确接受有界超卖。风险由 edge 本地负余额下限和 master 每节点滑动窗口结算熔断共同约束；权威余额允许在结算后为负，现有 master 鉴权和余额检查负责阻止后续中心侧消费。

master 心跳读取已经写入数据库的余额事实，不关闭既有 batch update。启用 batch update 时，实际双花上界是“batch 延迟 + heartbeat 周期”；关闭 batch update 时 batch 延迟为零。

settlement block 的连续序号、链式摘要、持久化 outbox、幂等确认和消费日志投影继续保留；租约签发、续借、关闭、归还和相关表、DTO、路由全部移除。结算事件必须改为携带余额来源、订阅标识和固定的策略/余额版本，master 结算事务改为实际扣减权威钱包、有限 token 或订阅额度。

策略快照 TTL 不再决定 master 宕机后的数据面可服务时长。edge 可以继续使用最后一次验证并应用的鉴权与计费策略，快照过期只冻结策略变更；只要鉴权索引、余额副本和本地账务仍可用，数据面继续服务。显式 token 到期时间仍按本地时钟执行，节点禁用、策略撤销等新变化要等控制面恢复后生效。

本 ADR 显式替代 [ADR 0002](./0002-local-leases-and-asynchronous-settlement.md)。
